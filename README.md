# أبو دانة TV — Launcher

تطبيق Android TV لشاشة TCL: أوقات الصلاة (أم القرى) مع تنبيه الأذان والانتقال للحرم المكي، طبخة اليوم، مشغّل IPTV، تطبيقات التلفزيون، وثيمات متعددة.

## طريقة بناء الـ APK بدون كمبيوتر قوي (GitHub)

1. سوّ حساب على github.com واعمل Repository جديد (مثلاً `AbuDanaTV`).
2. ارفع كل محتوى هذا المجلد (Add file → Upload files) واضغط Commit.
3. افتح تبويب **Actions**؛ البناء يشتغل لحاله ويخلص خلال 5 دقائق تقريباً.
4. افتح آخر تشغيل ← تحت **Artifacts** نزّل `AbuDanaTV-apk` (ملف zip فيه `AbuDanaTV.apk`).

## أو عن طريق Android Studio

افتح المجلد في Android Studio ← Build ← Build APK(s).

## التثبيت على التلفزيون

1. فعّل على التلفزيون: الإعدادات ← الجهاز ← الأمان ← **مصادر غير معروفة**.
2. انقل الـ APK بفلاش USB وافتحه بمدير الملفات، أو استخدم تطبيق **Send Files to TV** أو **Downloader**.
3. بعد التثبيت يظهر «أبو دانة» في قائمة التطبيقات.
4. عشان يصير هو الواجهة الرئيسية: اضغط زر Home، وإذا سألك اختر «أبو دانة» ← دائماً.
   (بعض أجهزة Google TV ما تسأل؛ وقتها افتحه من التطبيقات.)

## تعديل الواجهة

الواجهة كلها في `app/src/main/assets/index.html`.
